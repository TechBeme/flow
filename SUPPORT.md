# Support

## Questions and setup help

Use GitHub Discussions after it is enabled for the repository. Search existing documentation and discussions before posting, and never include credentials or private generated media.

## Bugs

Use the [bug report template](https://github.com/TechBeme/flow/issues/new?template=bug_report.yml) for reproducible product defects. Include the Flow commit, browser, deployment type, selected model, and sanitized error message.

## Feature ideas

Use the [feature request template](https://github.com/TechBeme/flow/issues/new?template=feature_request.yml). Describe the creative workflow and user outcome instead of only proposing an implementation.

## Security

Follow [SECURITY.md](SECURITY.md). Security reports do not belong in public issues or discussions.
